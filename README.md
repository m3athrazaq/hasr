# حَصْر — Hasr

عدّ الأغنام الحيّة بالكاميرا أثناء تفريغ السفن. تطبيق ويب يُثبَّت كتطبيق على **الأندرويد والآيفون والويندوز**، ويعمل بدون إنترنت بعد أول تشغيل.

**الرابط:** https://m3athrazaq.github.io/hasr/

## التثبيت

| الجهاز | الطريقة |
|---|---|
| أندرويد (كروم) | افتح الرابط ← قائمة ⋮ ← «تثبيت التطبيق» |
| آيفون (سفاري) | افتح الرابط ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية» |
| ويندوز (كروم أو إيدج) | افتح الرابط ← أيقونة التثبيت في شريط العنوان |

## كيف يعدّ

1. **الكشف:** نموذج ذكاء اصطناعي يعمل داخل الجهاز (WebGPU، أو المعالج عند عدم توفره) يكتشف كل رأس في كل إطار. نموذجان:
   - **من الأعلى:** نموذج مخصص للأغنام مدرّب على صور علوية (AUTH-Sheep).
   - **مائل أو جانبي:** YOLO26 (n أو s).
   يختار التطبيق النموذج تلقائياً حسب ما يراه قرب خط العدّ.
2. **التتبع:** كل رأس يأخذ رقماً ويُتبع بين الإطارات (مرشّح كالمان + ربط على مرحلتين على طريقة ByteTrack، مع استعادة الرأس بعد الاختفاء القصير).
3. **العدّ:** +1 عند عبور الخط في اتجاه الخروج، و−1 إذا رجع. منطقة حياد حول الخط تمنع العدّ المكرر للرأس المتردد.
4. **المراجعة:** الحالات المشكوك فيها (رأسان في إطار واحد، رأس ظهر بعد الخط دون رصد عبوره، عبور بثقة منخفضة، توقف الكاميرا) تُحفظ مع مقطع قصير، ولا يتغير العدد إلا بقرار المراجع.
5. **المطابقة:** عدّ لكل شاحنة، ومقارنة مع عدّ ثانٍ من فيديو التسجيل، ومع العدد المتوقع في بيان الشحن.

الحفظ مستمر على الجهاز: إذا أُغلق التطبيق أو انطفأ الجوال يمكن متابعة نفس العدّ.

## مصادر الصورة

- كاميرا الجوال أو كاميرا USB.
- **شاشة برنامج كاميرات المراقبة** على الويندوز (مشاركة النافذة).
- **ملف فيديو** مسجّل؛ يُحلَّل إطاراً بإطار بنفس الدقة مهما كانت سرعة الجهاز.

## للمطورين

```
node tools/serve.mjs . 8765        # خادم محلي مع ترويسات العزل
node test/sim.mjs 6                # اختبار محرك العدّ على تدفقات محاكاة
python3 tools/dumpdets.py VIDEO MODEL e2e 12 out.json   # كشف مرجعي (Python)
node test/rundets.mjs out.json run.json x1,y1,x2,y2 1    # عدّ على الكشف المرجعي
```

الملفات الأكبر من 20 ميجابايت مقسّمة إلى أجزاء (`files.json`) ليمكن رفعها من صفحة GitHub مباشرة.

---

**English.** Hasr counts live sheep with a camera during vessel discharge. It runs on-device in the browser (ONNX Runtime Web, WebGPU or multi-threaded WASM), tracks every animal across the counting line (Kalman + two-stage association), counts net crossings (forward +1, back −1), flags doubtful cases with a short clip for human review, and keeps the count safe across crashes. Install it from the link above on Android, iPhone or Windows.
